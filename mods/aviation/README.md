# 机场与飞机 — Minecraft 26.3 / Fabric

这是独立的飞机模组，包括普通飞机、战斗机、12 座客机、机炮、机场入口和六种自定义机场方块。客机乘客会从登机廊桥步行上机。

## 安装

- Minecraft **26.3**，Fabric Loader **0.19.5 或更新版本**，Java **25**。
- 把 `aviation-mod-1.0.4.jar` 和 `fabric-api-0.161.0+26.3.jar` 放进游戏实例的 `mods` 文件夹。升级时移除旧版飞机模组 JAR。
- 多人游戏需要服务器和所有玩家都安装模组与 Fabric API。
- 不要把源码 ZIP 或 `sources.jar` 当作模组安装。

## 驾驶

手持飞机物品，对宽阔平地右键放置，再对飞机右键进入。普通飞机、战斗机和一架客机也会在机场内预先停放。

右键上机后自动切换到第一人称驾驶视角，可以看到前方跑道并用鼠标观察；驾驶时自己的机身不会遮住画面，爬升、转弯和陡角度下降也保持前方视野。按 F5 可查看完整飞机，其他玩家同样能看见它；下机后恢复进入前的视角。飞机使用服务器统一计算移动，并在客户端平滑显示，避免驾驶时前后跳动。驾驶视角关闭摇晃。

**起飞必须有跑道。** 飞机在草地、石头、普通道路或停机坪上可以放置、驾驶和滑行，但即使超过 100 km/h 并按空格，也不能起飞。先滑行到自定义“机场沥青跑道”上，再加速起飞。跑道白色标线、黄色标线和嵌入式灯光可与沥青混铺；飞机下方必须完整铺好跑道，孤立的一块跑道不够。自建跑道同样有效，建议至少 8 格宽、250 格长。已经起飞后，可以飞越其他地形。

| 按键 | 功能 |
| --- | --- |
| W | 加速前进 |
| A / D | 左转 / 右转 |
| S | 减速刹车 |
| 空格 | 在自定义跑道上达到 **100 km/h** 后起飞；飞行时继续爬升 |
| Shift + W | 减速并缓慢下降，直到接地 |
| 单独按住 Shift | 落地后刹车，速度降至 5 km/h 以下自动下机；停稳时可直接下机 |
| G | 战斗机机炮，按住连续开火 |
| V | 飞机落地且速度低于 5 km/h 时离开 |

松开空格、保持足够速度时，飞机维持当前高度。速度低于 75 km/h 会下沉。驾驶界面显示速度、高度与起飞状态。Shift＋W 用于降落，不会误下机；下机时先松开 W，再单独按住 Shift。空中仍保留防误下机限制。

1.0.4 修复下降和着陆时的消失/掉出驾驶位问题：按住 Shift 时，玩家的位置持续随飞机更新，保持区块加载和飞机显示；Shift + W 即使已经减速至零，也会保留驾驶员，直到主动下机。接触障碍物只刹停，不再扣除飞机生命；下降免摔落伤害。飞机的显示范围覆盖机翼、机头和尾翼。飞机仍可被攻击损毁。

机炮默认使用 **G**，不会占用 R；可在“选项 → 控制 → 按键绑定 → 飞机操控”修改机炮与离机按键。普通飞机最高 260 km/h，战斗机最高 700 km/h，客机最高 340 km/h。机炮射程 120 格，每次命中造成 12 点伤害，每 4 游戏刻可开火一次，实体方块会挡住射线。

## 客机与乘客

机场第一座登机廊桥前预停一架客机。靠近后，12 名村民乘客会从廊桥步行经过连接通道，再从客机后侧登机；不是瞬间出现在座位上。登机期间客机不能滑行，驾驶界面显示乘客人数和登机状态。全部登机后即可滑行到跑道起飞。驾驶员有独立座位，即使 12 名乘客已上机，仍可右键进入驾驶舱。

自制客机也能接客：停在机场五座廊桥之一的前方，机头朝向跑道（朝北，偏航角约 180°），停稳后自动开始登机。五个停靠中心分别是 `(120.5, 64, 177.5)`、`(164.5, 64, 177.5)`、`(208.5, 64, 177.5)`、`(252.5, 64, 177.5)`、`(296.5, 64, 177.5)`，需要距离停靠中心小于 2 格。放置飞机时朝北面向跑道即可设置这个方向。

每架客机自动接客一次。乘客与未完成的登机队列会保存，退出重进可继续登机；驾驶员下机时乘客仍留在机舱。乘客使用 Minecraft 原生村民模型。机场以外也可以驾驶空客机，但不会自动生成乘客。

## 机场

放置“机场入口”会开始建造并传送。首次使用需要等待进度完成，之后再次使用可直接进入。机场在独立的超平坦维度中生成，地面和跑道均为 Y=63，包括 **480 × 32 格跑道**、平行滑行道、停机坪、玻璃航站楼、五座登机廊桥、塔台、雷达、两座机库、停车区域和夜间跑道灯。跑道、标线、停机坪和灯光均有独立模组方块及材质。

机场到达广场的“机场入口”可以右键返回进入前的位置。机场建造进度、停放飞机和玩家返回位置会保存；再次进入不会覆盖已建好的机场。整个设施约 512 × 320 格，首次建造按批次进行。

机场维度关闭自然刷怪和动物生成、幻翼与巡逻队等特殊刷怪、刷怪笼及雷暴骷髅马生成。已有机场升级后同样生效，无需重建；主世界、下界和末地保留原来的刷怪规则。廊桥乘客和飞机照常生成，玩家主动使用刷怪蛋或命令仍可放置生物。升级不会删除已经存在的生物。

创造模式下，飞机物品位于“工具与实用物品”，机场入口及机场方块位于“功能方块”。开启作弊后也可使用：

```mcfunction
/give @s aviation:plane
/give @s aviation:fighter
/give @s aviation:airliner
/give @s aviation:airport
```

## 工作台配方

普通飞机：

```text
铁锭  铁锭  铁锭
玻璃  熔炉  玻璃
铁锭  红石  铁锭
```

战斗机：

```text
铁锭  钻石  铁锭
玻璃  熔炉  玻璃
铁锭  红石  铁锭
```

客机（7 个铁锭 + 1 架普通飞机 + 1 个红石）：

```text
铁锭  铁锭      铁锭
铁锭  普通飞机  铁锭
铁锭  红石      铁锭
```

机场入口：

```text
铁锭  红石  铁锭
玻璃  指南针  玻璃
铁锭  红石  铁锭
```

自定义方块的无序配方：砂砾 + 煤炭 → 16 跑道沥青；跑道沥青 + 白色 / 黄色染料 → 对应标线方块；砂砾 + 白色染料 → 16 停机坪混凝土；玻璃 + 萤石粉 + 铁锭 → 4 机场灯。

## 编译与验证

在 Java 25 环境运行 `./gradlew build`。1.0.4 的全部 17 项服务器 GameTests 已通过，覆盖跑道限制、起飞速度、下降与防误下机、驾驶权限、机炮命中与墙体遮挡、存档读写、物品放置、真实工作台配方、机场生成和往返传送，以及乘客沿廊桥步行登机、队列存档恢复和独立驾驶员座位。机场维度刷怪隔离检查验证自然与特殊刷怪关闭、其他维度规则不变、乘客仍可生成。1.0.4 新增三种飞机按住 Shift 后持续更新驾驶员位置、受损状态着陆碰撞、摔落伤害防护、零速着陆输入顺序及新地形着陆检查。

图形客户端测试使用 `./gradlew runClientGameTest -PclientTests=true`，需要可用显示环境。1.0.4 已在 Minecraft 26.3 实际客户端中逐一验证三种飞机：右键上机、自动前方驾驶视角、连续前进无向后跳动、达到起飞速度后空格起飞、持续爬升 350 刻、俯冲角超过 30° 后继续 Shift + W 降落、玩家位置持续跟随机体、落地后保留驾驶员与满生命、松开 W 后按住 Shift 下机及视角恢复。下机后检查了服务器和客户端的飞机实体都仍存在，并保存外观截图；已查看前方视野、陡角度下降和着陆后的游戏截图。

测试专用维度 Mixin 让原版 GameTestServer 加载数据包维度；它只存在于测试源码集，**不包含在交付 JAR**。测试任务只清理 `build/run/gameTest/world` 下的测试世界，不操作玩家存档。
